# merge_sort


## Description

A method takes an array of integers and return a new array with integers in numerical order.

## Purpose

To strengthen my understanding of writing a recursive method.

In this exercise I practiced:

- using TDD to identify with to build and which edge cases are appropriate to test
- breaking a larger problem into smaller, recursive subproblems
- combining smaller sorted arrays back together into a final sorted array

## How to Run

```ruby
example_array = [3, 5, 6, 2, 100]
p merge_sort(example_array)
```

## Example Output

```ruby
[2, 3, 5, 6, 100]
```
